# Fontes

Este pacote **não distribui arquivos de fonte**.

Sugestão: Fraunces (display) e Instrument Sans (UI) do Google Fonts. Verifique termos/licença antes da implementação e, para performance e privacidade, prefira hospedagem própria obtida das fontes oficiais e com arquivos licenciados. Sempre disponibilize fallback system fonts.

Link CSS de demonstração (opcional, requer internet):
`https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400;9..144,500;9..144,600&family=Instrument+Sans:wght@400;500;600;700&display=swap`
